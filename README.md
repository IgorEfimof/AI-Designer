# 🎨 AI Designer

**AI Designer** — это браузерный графический редактор для быстрого создания продающих карточек товаров для маркетплейсов (Ozon, Wildberries, Яндекс Маркет). 

Инструмент объединяет удобный слоёный интерфейс и возможности искусственного интеллекта для анализа фото и генерации текстов, позволяя создавать профессиональные макеты без сложных программ вроде Photoshop.

## 🚀 Основные возможности
- **AI-анализ фото:** Автоматическое определение цветовой палитры, категории товара и рекомендации по композиции.
- **AI-генерация текстов:** Создание продающих названий, бейджей и характеристик на основе загруженного фото.
- **Готовые форматы:** Предустановленные размеры холста для Ozon (1200×1600), Wildberries (900×1200), Яндекс Маркета и квадрата.
- **Слоёный редактор:** Работа с текстом, фигурами, фото, масками обрезки и изменением порядка слоёв.
- **Инструменты композиции:** Встроенные направляющие «Золотое сечение» и «Спираль Фибоначчи».
- **Полная приватность:** Проект работает полностью в браузере. Автосохранение в LocalStorage, отправка данных в AI происходит только по вашему запросу и с вашим API-ключом.
- **Экспорт:** Сохранение готового макета в PNG или JPG высокого качества.

## ⚙️ Как запустить локально
Проект не требует сборки, серверной части или установки зависимостей (Node.js и т.д.).
1. Скачайте файлы репозитория или откройте проект через GitHub Pages.
2. Откройте файл `index.html` в любом современном браузере.
3. Перейдите в раздел «Настройки», укажите свой API-ключ (например, от OpenRouter) и начните работу.

> **Примечание:** Для работы AI-функций (анализ фото, генерация текстов) требуется подключение к интернету и ваш собственный API-ключ. Базовый графический редактор работает полностью офлайн.

## 🛠️ Технологии
- HTML5, CSS3 (Grid/Flexbox, CSS-переменные, адаптивная вёрстка)
- Нативный JavaScript (ES6+, Canvas API для рендеринга и экспорта)
- Интеграция с AI-моделями через OpenRouter API (Vision и Text)
- LocalStorage / IndexedDB для локального хранения данных и автосохранения
- *Никаких тяжелых фреймворков: максимум производительности и чистый код.*
